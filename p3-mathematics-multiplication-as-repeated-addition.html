Multiplication as repeated addition

Lesson notes • worked example • practice • suggested answers

Download P3 notes PDF

Learning support material. Follow your current school syllabus and teacher’s guidance.

Learning outcomes

  • Describe multiplication as equal groups
  • Write repeated addition as multiplication
  • Solve simple multiplication questions

Lesson notes

Multiplication is a quick way of adding equal groups. If there are 3 groups with 4 mangoes in each group, we can add 4 + 4 + 4.

The repeated addition 4 + 4 + 4 equals 12. It can be written as 3 × 4 = 12, meaning 3 groups of 4.

Remember that equal groups contain the same number of objects in each group.

Worked example

5 + 5 + 5 + 5 = 20, so 4 × 5 = 20.

Everyday-life activity

At home or at school, a learner meets a situation involving multiplication as repeated addition. Use the lesson idea to answer the practice questions and explain how you know your answer is correct.

Practice questions

  1. Write 3 + 3 + 3 + 3 as a multiplication sentence.
  2. 6 × 2 = ?
  3. There are 4 baskets with 3 oranges in each. How many oranges are there?
Show suggested answers
  1. 4 × 3 = 12
  2. 12
  3. 12 oranges

How to present answers

  1. Write neatly and answer what the question asks.
  2. For calculations, show the number sentence and answer.
  3. For explanations, give one clear fact or reason.

Suggested marking: 1 mark for each correct fact/step unless the teacher's marking guide says otherwise.

Revision checklist

  • I can explain the main idea in my own words.
  • I can solve a new question without copying the example.
  • I can check my answer and correct mistakes.
