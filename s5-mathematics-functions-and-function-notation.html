Functions and function notation

Lesson notes • worked example • practice • suggested answers

Download S5 notes PDF

Learning support material. Follow your current school syllabus and teacher’s guidance.

Learning outcomes

  • Explain the meaning of a function
  • Evaluate a function for a given input
  • Find a simple value of an unknown using function notation

Lesson notes

A function is a rule that assigns exactly one output to each allowed input. The notation f(x) means the value of function f when the input is x; it does not mean f multiplied by x.

To evaluate a function, substitute the input wherever x appears and simplify using the order of operations.

The domain is the set of allowed inputs. Some functions have restrictions, for example a denominator must not be zero.

Worked example

If f(x) = 2x² - 3, then f(2) = 2(2²) - 3 = 8 - 3 = 5.

Scenario-based revision task

A water tank’s monitoring system uses the function f(x) = 3x + 1 to estimate a reading from sensor input x. A second function g(x) = x² − 5 is used for another calculation.

Apply your learning

  1. Find f(4) and show substitution. (2 marks)
    Suggested answer: f(4) = 3(4) + 1 = 13.
  2. Calculate g(−2). (2 marks)
    Suggested answer: g(−2) = (−2)² − 5 = 4 − 5 = −1.
  3. For h(x) = 1/(x − 3), state the input that is not allowed and explain why. (2 marks)
    Suggested answer: x = 3 is not allowed because it makes the denominator zero.
Teacher-style marking guide

Award marks for correct substitution, evaluating powers before subtraction, and identifying division by zero.

These are original practice items for learning; they are not official UNEB questions or an official marking scheme.

Practice questions

  1. If f(x)=3x+1, find f(4).
  2. If g(x)=x²-5, find g(-2).
  3. For h(x)=1/(x-3), state the value of x that is not allowed.
Show suggested answers
  1. 13
  2. -1
  3. x = 3

How to present answers

  1. Read: underline the command word (state, describe, explain, calculate, compare or suggest).
  2. Use evidence: select facts or figures from the question scenario.
  3. Explain: give a clear reason or show each calculation step, including units where needed.
  4. Conclude: state the final answer or recommendation directly.

Marking guide: award credit for relevant facts, correct method, application to the scenario, and a justified conclusion. Accept other scientifically/mathematically correct answers.

Revision checklist

  • I can explain the main idea in my own words.

  • I can check my answer and correct mistakes.
